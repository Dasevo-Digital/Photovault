# Gemeinsame Abgleichsübersicht

Flutter-Oberfläche für Desktop und Telefon mit eigenen deutschen und
englischen Übersetzungen. `Abgleichsuebersicht(abgleich: ...)` verwendet
die verschlüsselte Warteschlange und dauerhaften Konfliktfälle aus `kern`.
Die Widgetregressionen liegen im Hauptprojekt unter
`test/abgleichsuebersicht_test.dart`.
