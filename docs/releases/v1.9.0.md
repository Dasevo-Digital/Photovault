# Photo Vault 1.9.0

Windows kommt als dritte Plattform dazu. Dazu ein Fehler, der jede
AVIF-Datei betraf – auch unter Linux.

**Die Datenbank bleibt auf Fassung 45.** Keine Migration.

## Windows

Die Anwendung läuft unter Windows 10 und 11 mit allem, was die anderen
Fassungen können: Bibliothek, Entwickeln, Gesichter, Texterkennung,
Bildbeschreibung, Objektentfernung, Videoschnitt und -wiedergabe.

Die Werkzeuge für iPhone-Fotos, RAW-Dateien und Video sind **mitgeliefert**.
Windows böte für HEIC zwar eine eigene Schnittstelle an, öffnet damit aber
nur, wer die HEVC-Erweiterung im Store kauft. Eine Fotoverwaltung, die
iPhone-Fotos erst nach einem Kauf anzeigt, ist keine – deshalb liegt
alles Nötige im Paket, so wie unter Linux im Flatpak.

Ausgeliefert wird ein Verzeichnis zum Auspacken, kein Installationspaket.
Auspacken, `photo_vault.exe` starten, fertig.

## AVIF-Fotos blieben ohne Vorschau

AVIF-Dateien wurden an den RAW-Entwickler weitergereicht statt an die
Bibliothek, die HEIC und AVIF liest. Der RAW-Entwickler kann kein AVIF –
die Fotos bekamen deshalb gar keine Vorschau und liessen sich nicht
öffnen.

Der passende Dekoder war die ganze Zeit vorhanden, die Datei kam nur nie
bei ihm an. **Betrifft Linux ebenso**; unter macOS ist AVIF nie
betroffen gewesen.

## Kleinigkeiten

**Videowiedergabe.** Der Dateipfad wird jetzt immer vollständig
weitergereicht. Ein verkürzter Pfad kam in der Wiedergabe-Bibliothek als
nicht vorhanden an – ohne Dauer, ohne Bild und ohne Fehlermeldung.

**Linux-Bereitschaftsprüfung.** Das Hilfsskript meldete weiterhin
„Entwickeln" und „Texterkennung" als nicht umgesetzt. Beides gibt es seit
Langem. Der Abschnitt sagt jetzt, was ohne die einzelnen Werkzeuge
tatsächlich fehlt.

## Einspielen

**Windows** – `PhotoVault-1.9.0-windows-x64.zip` auspacken und
`photo_vault.exe` starten. Beim ersten Start meldet sich SmartScreen, weil
das Programm nicht signiert ist; über **Weitere Informationen → Trotzdem
ausführen** startet es.

**Linux**

```
flatpak remote-add --if-not-exists --user flathub \
    https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user PhotoVault-1.9.0-x86_64.flatpak
flatpak run com.example.PhotoVault
```

**macOS** – Archiv auspacken, `Photo Vault.app` an den gewünschten Ort
legen. Mindestens macOS 14.0.

## Hinweis zur Signatur

Weder die macOS- noch die Windows-Fassung ist mit einem gekauften
Zertifikat signiert. Unter macOS meldet sich Gatekeeper – über
**Rechtsklick → Öffnen** startet die App trotzdem. Unter Windows meldet
sich SmartScreen, siehe oben.
