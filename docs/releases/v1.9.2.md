# Photo Vault 1.9.2

Modell-Downloads setzen fort, statt neu zu beginnen. Dazu erklärt sich das
Windows-Paket künftig selbst.

**Die Datenbank bleibt auf Fassung 45.** Keine Migration.

## Ein Abbruch verwarf bisher alles

Beim Nachladen eines KI-Modells reichte eine einzige unterbrochene
Verbindung, und der gesamte Fortschritt war weg. Bei
`clip_image_encoder.onnx` sind das **352 MB**, die komplett noch einmal
durch die Leitung mussten — und wenn es beim zweiten Mal wieder
unterbrach, wieder.

Jetzt gilt:

- **Drei Anläufe** je Datei statt einem.
- **Fortsetzen** dort, wo es aufhörte (HTTP-Bereichsanfrage), statt neu zu
  beginnen.
- **Zeitgrenzen**: Eine Verbindung, die keine Daten mehr liefert, wird nach
  einer Minute abgebrochen, statt endlos zu warten.

Die **Prüfsumme bleibt die Garantie**. Kommt beim Fortsetzen irgendetwas
durcheinander, fällt es dort auf und der Anlauf beginnt von vorn — eine
Datei mit falscher Prüfsumme wird nie abgelegt. Beantwortet ein Anbieter
eine Bereichsanfrage nicht wie verlangt, wird ebenfalls sauber neu geladen,
statt an den Rumpf anzuhängen.

## Das Windows-Paket erklärt sich

Zwei Beilagen, weil beides bisher nirgends stand:

**`LIESMICH.txt`** — dass dieser Ordner das Programm *ist*: Es gibt keine
Installation, keinen Eintrag unter „Apps & Features", und wird der Ordner
gelöscht, ist die Anwendung weg. Ausserdem, wo die eigenen Daten liegen
(`%APPDATA%\com.example\photo_vault\PhotoVault\`) — sie überleben das
Auspacken einer neuen Fassung, bleiben beim Löschen aber zurück.

**`Verknuepfung-anlegen.cmd`** — legt eine Verknüpfung im Startmenü an, die
auf die `photo_vault.exe` in diesem Ordner zeigt. Sonst ändert sie nichts.
Das Paket bleibt portabel; wer den Eintrag nicht will, führt die Datei
einfach nicht aus.

## Einspielen

**Linux**

```
flatpak install --user PhotoVault-1.9.2-x86_64.flatpak
flatpak run com.example.PhotoVault
```

**macOS** – Archiv auspacken, `Photo Vault.app` an den gewünschten Ort
legen. Mindestens macOS 14.0.

**Windows** – `PhotoVault-1.9.2-windows-x64.zip` auspacken und
`photo_vault.exe` starten. `LIESMICH.txt` im Paket erklärt den Rest.

## Hinweis zur Signatur

Weder die macOS- noch die Windows-Fassung ist mit einem gekauften
Zertifikat signiert. Unter macOS meldet sich Gatekeeper – über
**Rechtsklick → Öffnen** startet die App trotzdem. Unter Windows meldet
sich SmartScreen; über **Weitere Informationen → Trotzdem ausführen**
startet sie.
