# Wettbewerbsvergleiche

Auswertungen aus der Vergleichsreihe (August 2026) als eigenständige HTML-Seiten – ein Snapshot
zum Zeitpunkt des Commits, ohne externe Abhängigkeiten direkt im Browser zu öffnen.

Vergleich und Fahrplan liegen in der **3. Auflage** vor, geprüft am Quellstand der Version 0.4.0.

- **[photo_vault_im_vergleich.html](photo_vault_im_vergleich.html)** — Funktionsumfang gegen digiKam,
  Immich, PhotoPrism, Apple Photos, Mylio, Excire Foto, Peakto, Lightroom (18 Kriterien).
- **[feature_fahrplan.html](feature_fahrplan.html)** — Vorschläge für als Nächstes sinnvolle Features,
  abgeleitet aus der Konkurrenz-Recherche.
- **[optik_und_usability.html](optik_und_usability.html)** — Visuelles Design und Bedienbarkeit gegen
  Apple Photos, Lightroom, digiKam, Immich, Photo Mechanic, darktable.
